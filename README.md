#  Desenvolvimento de Sistemas & Calculadora Java Swing

Este repositório reúne exercícios práticos de Programação Orientada a Objetos (POO), estruturas de dados e a implementação completa de uma **Calculadora Desktop** utilizando **Java Swing**.

---

## Destaques do Projeto: Calculadora Complexa

A calculadora é uma aplicação gráfica interativa com foco em usabilidade e suporte a atalhos de teclado.

###  Funcionalidades
- **Operações Básicas:** Soma, Subtração, Multiplicação e Divisão.
- **Suporte a Teclado Físico:** Mapeamento completo dos números (0-9), vírgula, operadores (`+`, `-`, `*`, `/`) e tecla `Enter` para efetuar o cálculo.
- **Tratamento de Exceções:** Mensagens amigáveis para erros como divisão por zero e formatação de números.
- **Bloqueio de Edição Direta:** Prevenção de erros ao introduzir caracteres inválidos no visor.

---

##  Estrutura do Repositório

- `src/interfaces/`: Contém as telas da aplicação Swing (`CalculadoraComplexa.java`).
- `src/encapsulamento/`: Exercícios de abstração e encapsulamento em Java.
- `src/estrutura/`: Exercícios de laços de repetição, vetores e estruturas condicionais.
- `src/resources/`: Imagens e recursos visuais da interface.
